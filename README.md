# Task Manager API

REST API for task management built with Python and FastAPI.

## Tech Stack

- Python
- FastAPI
- Pytest
- HTTPX
- Ruff

## Running locally

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the server:

```bash
fastapi dev app/main.py
```
